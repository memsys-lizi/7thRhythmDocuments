# 官方关卡脚本

## 模块边界

本模块覆盖 `Level_*` 系列脚本，以及它们继承的 `LevelBase`。

## 初步范围

官方关卡脚本通常以 `Level_` 开头，例如：

- `Level_Intro`
- `Level_Boss2`
- `Level_Freezeshot`
- `Level_Tutorial_*`
- `Level_Oriental*`
- `Level_Montage`

## 写作重点

- 关卡脚本继承关系。
- 特殊事件、特殊判定、特殊视觉效果。
- 与 `LevelBase` 默认行为的差异。
- 是否存在只服务特定场景的临时逻辑。
