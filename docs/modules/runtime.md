# 运行时游戏系统

## 模块边界

本模块覆盖关卡运行期间的核心系统：

- 节拍和判定。
- 行、房间、窗口和角色显示。
- 音频加载与播放。
- VFX、相机、屏幕效果。
- 场景切换和暂停流程。
